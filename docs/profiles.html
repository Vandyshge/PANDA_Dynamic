Ширина и асимметрия.

Плотность описывает ширину жидкого мостика. Центр масс каждого слоя показывает, к какому мениску он смещён.

Контактные углы

Сила и сопротивление

Оба угла вычисляются из силового баланса и сохранения объёма. Изменение силы сразу меняет ρ(z), q(z) и мениски.

Параметры профилей

Профили безразмерные: ζ = z/H, R = ρ/ρl, Q = q/H. Вне эффективного жидкого интервала Q не определён.

При перестановке менисков плотность совпадает, а Q меняет знак. Серые полосы — исключённые пристеночные области.

Геометрия поперечного сечения

Два мениска, общий центр масс

Зелёная область — однородная жидкость. Левый мениск задаёт θrec, правый — θadv. Вертикальная штриховая линия проходит через общий центр масс.

Q отсчитывается от взвешенного по массе центра всего мостика. Поэтому его среднее с весом R равно нулю, хотя отдельные слои смещены.

Плотность — сумма

R(ζ) = d + b1(ζ) + b2(ζ)ℓ

R инвариантен к обмену θ₁ ↔ θ₂. При θ₁ = θ − ε, θ₂ = θ + ε производная ∂R/∂ε в ε = 0 равна нулю: малое расщепление входит со второго порядка.

Центр масс — разность

Q(ζ) = b2 − b12 − C

Q меняет знак при обмене углов и линейно откликается на малую асимметрию. Совместный фит R и Q позволяет различить левую и правую ветви.

Полная модель и функция ошибки

h = 1/2 − δ; bᵢ — отклонение кругового мениска от точки контакта. Для |ζ| < h:

bᵢ(ζ) = − cos θᵢ (h² − ζ²)√(h² − cos²θᵢ ζ²) + h sin θᵢ

Эта форма регулярна при 90°. Uᵢ = ∫ bᵢ dζ, Vᵢ = ∫ bᵢ² dζ по [−h, h], A = 2hd + U₁ + U₂.

C = d(U₂ − U₁) + V₂ − V₁2A,   d = φℓ − 2U(θ₀, h)2h

В режиме сохранения объёма выполняется U₁ + U₂ = 2U(θ₀, h); при независимом изменении углов выводится отклонение площади от φℓ. Для свободных углов подписи rec/adv обозначают расположение интерфейсов, даже если порядок углов обратный.

χ² = ∑k ∈ Iρ (Rk − R̄k)²s²R,k + ∑k ∈ Iq (Qk − Q̄k)²s²Q,k

В МД предсказания интегрируются по реальным конечным бинам, пустые q-бины пропускаются, а пристеночные слои исключаются из фита. Здесь показаны непрерывные аналитические профили однородной жидкости; молекулярная слоистость и пар не моделируются.
