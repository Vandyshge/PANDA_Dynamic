Сплошная линия — θadv, штриховая — θrec. Маркеры показывают выбранную силу и модель.

Силовой баланс

2Lyγlv(cos θrec − cos θadv) = Feff

Множитель 2 учитывает две стенки. Дополнительное сопротивление вычитается из полной внешней силы.

Сохранение объёма

G(θrec) + G(θadv) = 2G(θ₀)
G(θ) = 2θ + sin 2θ − π8 cos²θ

Углы в формулах — в радианах. При θ = π/2 используется непрерывный предел G = 0; G′(π/2) = 1/6.

Линейное приближение и границы модели

Положим θrec = θ₀ + u, θadv = θ₀ + v. Тогда G′(θ₀)(u + v) = 0 и 2Lyγlvsin θ₀(v − u) = Feff.

θrec,adv ≈ θ₀ ∓ Feff4Lyγlvsin θ₀

Средний угол изменяется только со второго порядка. Предполагаются круговые мениски, постоянный объём и неизменное расстояние между точками контакта на стенках. Если для заданной силы нет пары углов в [0°, 180°], кривая заканчивается: модель достигла геометрического предела.

При vx = bFext угловые данные определяют γth = γlv/(1 − βb). Они не позволяют независимо восстановить γlv и β. Постоянное сопротивление здесь иллюстрирует порог, а не доказывает закон сухого трения.
