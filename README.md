# PANDA Dynamic

Интерактивный сайт по PANDA-D: движущийся жидкий roll в щелевой нанопоре.

**Сайт:** https://vandyshge.github.io/PANDA_Dynamic/

- **Теория:** нелинейное расщепление наступающего и отступающего углов от внешней силы; без сопротивления, с постоянным сопротивлением и с сопротивлением βv при v = bF. Сравнение моделей, линейное приближение, предел существования, выгрузка CSV/SVG.
- **Профили:** плотность R = ρ/ρ_l и асимметрия центра масс Q = q/H, круговые мениски, сохранение объёма, перестановка углов, перенос состояния из теории, выгрузка CSV/SVG. Два режима: ручное задание углов и автоматическое вычисление обоих углов по силе и выбранной модели сопротивления непосредственно на странице профилей.
- **Источники:** обозначения, происхождение формул, ограничения интерпретации.

Визуальное оформление основано на [PANDA Polygon](https://github.com/Vandyshge/PANDA_Polygon), включая предоставленный логотип. Все вычисления выполняются в браузере. Нет внешних JS-зависимостей, серверных вычислений, аналитики или загрузки данных пользователя.

## Научная модель

Формулы взяты из авторской рукописи *Dynamic contact-angle splitting of a liquid roll in a slit nanopore*, PRF-редакция от 10.10.2026, и аналитического модуля PANDA-D/COM (`panda_com_analytic.py`, версия из анализа 06.10.2026). Черновик не публикуется в этом репозитории. Сайт показывает аналитическую модель, а не новые или полностью обработанные МД-результаты.

В теории решаются:

    G(theta_rec) + G(theta_adv) = 2 G(theta0)
    2 Ly gamma (cos(theta_rec) - cos(theta_adv)) = F_eff
    G(theta) = (2 theta + sin(2 theta) - pi) / (8 cos(theta)^2)

Для численной устойчивости G вычисляется через интеграл мениска U(theta, 1/2); в окрестности 90° используются ряды. G(90°) = 0, G'(90°) = 1/6. Углы решаются монотонной бисекцией с проверкой границы геометрического существования. Радианы используются внутри модели; интерфейс показывает градусы.

В профилях ζ = z/H, ℓ = Lx/H, h = 1/2 − δ. Контактная ширина d фиксируется равновесным углом и φ. Общий COM вычитается с весом ширины слоя. Q не определён в пустых слоях; CSV содержит пустые поля, а не нули. Проверяются положительная контактная ширина, отсутствие пересечений и неперекрытие периодических образов. Профили непрерывные; для МД нужны интегрирование по конечным бинам, учёт паровой фазы и исключение слоистости.

Вязкое сопротивление здесь задаётся произведением βb, а не независимо определённым β. Предположение v = bF обязательно для этой иллюстрации. Фитированный γ_th при игнорировании сопротивления не является независимым измерением γ_lv.

## Запуск и проверка

Требуется Node.js (без установки пакетов):

    npm start
    npm test

Локальный адрес: http://127.0.0.1:4175/

GitHub Pages публикует `docs/` из ветки `main`. Достаточно обновить файлы и отправить коммит; отдельная сборка не нужна.

## Файлы
